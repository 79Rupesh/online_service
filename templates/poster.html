MP Suvidha · Technical Architecture

Madhya Pradesh Digital Services Demonstration Platform
Production Audit Grade v3.2

🏛️ Architecture & Backend

Built with robust Python Flask blueprints, REST APIs, and SQLite database with foreign keys and connection pooling.

  • Flask 3.x with modular blueprints
  • Signed Bearer session tokens
  • Secure password hashing (pbkdf2:sha256)
  • High-performance parameterized queries

🌐 Bilingual English & Hindi

Complete dual-language localized interface supporting instantaneous switching across all components.

  • Centralized translation dictionary
  • Dynamic DOM updates with data-i18n
  • Bilingual SQLite service catalog
  • Bilingual full-text service search

🛡️ Cybersecurity & Access Control

Department-level role-based authorization restricting officers to their assigned administrative domain.

  • Login brute-force rate limiting
  • Magic byte file upload verification
  • Strict path traversal prevention
  • Citizen document confidentiality

📜 Genuine QR Verification Engine

Generates high-resolution demonstration certificates rendered with real Unicode Devanagari typography, official borders, security seal, and a genuine scannable QR code linking to digital verification.

👥 Department-Wise Workflow

Separates roles between Citizens (service discovery, submission, tracking), Officers (department-restricted verification and status updates), and Administrators (master service management, announcements, and user governance).
